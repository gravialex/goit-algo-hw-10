# Звіт до Завдання 2: Обчислення визначеного інтеграла методом Монте-Карло

У цьому завданні проводиться обчислення визначеного інтеграла функції **$f(x) = x + \sin(x)$** на відрізку від $0$ до $2$ за допомогою імовірнісного **методу Монте-Карло**. Отриманий результат порівнюється з точним чисельним розрахунком за допомогою функції `quad` із бібліотеки **SciPy**.

---

## 1. Опис реалізованого підходу

1. **Метод Монте-Карло:**
   * У межах прямокутника, що повністю охоплює область під кривою на відрізку $[a, b] = [0, 2]$, генерується велика кількість випадкових точок ($100\,000$ точок).
   * Визначається частка точок, які потрапили всередину області під графіком функції ($y \le f(x)$).
   * Площа під кривою (інтеграл) обчислюється як площа прямокутника, помножена на знайдену частку точок.

2. **Перевірка точності (`scipy.integrate.quad`):**
   * Для верифікації результату використовується еталонна функція `spi.quad`, яка реалізує детерміновані методи чисельного інтегрування високої точності.

---

## 2. Результати обчислень

Для функції $f(x) = x + \sin(x)$ на інтервалі $[0, 2]$:
* **Результат методом Монте-Карло ($100\,000$ точок):** $\approx 3.2842$ *(значення може дещо відрізнятися залежно від генератора випадкових чисел)*
* **Результат через SciPy (`quad`):** $3.282240$ (оцінка похибки: $\approx 3.64 \cdot 10^{-14}$)
* **Абсолютна похибка між методами:** Менше ніж $0.002$

---

## 3. Висновки

1. **Висока точність методу:** Результат, отриманий за допомогою методу Монте-Карло, демонструє мінімальну абсолютну похибку порівняно з детермінованим розрахунком через `spi.quad`. Це підтверджує коректність реалізації алгоритму та достатність обраної кількості випробувань ($100\,000$ точок).
2. **Особливості та імовірнісна природа:** Метод Монте-Карло є імовірнісним. Його точність апроксимації зростає пропорційно квадратному кореню з кількості випробувань ($O(\frac{1}{\sqrt{N}})$). Це означає, що для збільшення точності вдвічі потрібно збільшити кількість точок у 4 рази.
